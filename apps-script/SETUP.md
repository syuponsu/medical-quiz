# 結果ログ（スプレッドシート自動記録）のセットアップ手順

クイズの結果を Google スプレッドシートに自動で溜めるための設定です。
一度やれば以降は自動で記録されます。

## 対象スプレッドシート
- 名前：**看護クイズ_結果ログ**
- URL：https://docs.google.com/spreadsheets/d/1bHwWkuhKWG1mPxqorpX4L9SLuThA2adJCYHuTV6TGog/edit

## 手順

1. 上のスプレッドシートを開く
2. メニュー **拡張機能 → Apps Script** を開く
3. 開いたエディタの中身をすべて消し、この隣の **Code.gs** の内容を全部貼り付けて保存（💾）
4. 右上の **デプロイ → 新しいデプロイ** をクリック
5. 歯車⚙️（種類の選択）→ **ウェブアプリ** を選ぶ
6. 設定を次のようにする：
   - 説明：任意（例「看護クイズ結果受信」）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**  ← これが重要（スマホから送れるように）
7. **デプロイ** を押す → 初回は権限の承認を求められるので許可する
8. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピー
9. そのURLを Claude（黒コ）に貼って伝える
   → こちらでアプリに設定し、再公開して接続完了です

## 動作確認（任意）
- コピーしたURLをブラウザで開いて「正常に動作しています」と表示されればOK
