# 設計：意識レベルの測り方（JCS/GCS）を脳出血教材に追加する

作成日：2026-07-27

## 背景・目的

JCS・GCS の基準を暗記できていないという課題がある。実際、看護クイズ「脳出血（急性期）」の直近の結果は 10/21 正解で、要復習に残った 13 問のうち最多の 4 問が意識レベルの評価に関する問題だった。

意識レベルは脳出血・くも膜下出血・DKA いずれの学習ページでも観察セットの筆頭に置かれている土台の物差しである。ここが不安定だと、部位診断の読み替えも急変の察知も同時にぐらつく。

**ゴールは「手元を見ずに JCS 20・GCS E3V3M5 と判定できる状態」**。早見表を引ければよい、ではなく暗記して頭から出せることを目指す。

## スコープ

### やること

1. Notion ページ「🧠 脳出血（急性期）— 実務版」に新セクションを追加する
2. その内容を `topics/ich.learn.html` に反映する
3. `topics/ich.json` に JCS/GCS の判定を問うクイズ問題を 3 問追加する

### やらないこと

- **小児用スケール**（小児 GCS、乳児の評価）は入れない。対象病棟の患者層と合わない
- **SAH・DKA の学習ページへの展開**はしない。今回は脳出血ページ内に閉じる
- **共通トピックとしての切り出し**はしない。JCS/GCS は 3 疾患に登場する横断的な内容であり将来的に独立トピック化する余地はあるが、今回は最小の変更で効果を確かめることを優先する
- **医療知識_DB の想起カード追加**はしない。このページには関連カードが 12 枚紐づいており、暗記という目的にはカードも適するが、今回はクイズ側で定着を確認する。効果を見てから判断する

## 設計

### 1. 置き場所

「受け持ち時の観察セット」の直後、「データの読み方（3本柱）」の手前に新セクションを挿入する。

```
## 受け持ち時の観察セット      ← 表の筆頭で「意識＝JCS・GCS が最重要」と述べている
## 意識レベルの測り方（JCS/GCS）   ← ★ここに新設
## データの読み方（3本柱）
```

観察セットで「最重要」と宣言した直後に、その物差しの中身が来る流れになる。

### 2. JCS：9 個の数字ではなく「3 × 3 の枠」で覚える

覚える対象を減らすことを設計の中心に置く。まず桁を決める軸を 1 本だけ示す。

| 桁 | 覚醒の状態 | 数字 |
|---|---|---|
| I（1桁） | 刺激しなくても覚醒している | 1・2・3 |
| II（2桁） | 刺激すると覚醒する（刺激をやめると眠る） | 10・20・30 |
| III（3桁） | 刺激しても覚醒しない | 100・200・300 |

そのうえで **各桁の中の 1・2・3 も「軽い → 重い」で共通**であることを示す。この 2 階建てを入れれば、覚えるのは 9 個の数字ではなく「桁の軸」＋「各桁 3 段階」になる。

続けて 9 項目の正確な文言を表で置く。実装時に原典で文言を確認すること。

- I-1 だいたい意識清明だが今ひとつはっきりしない／I-2 見当識障害がある／I-3 自分の名前・生年月日が言えない
- II-10 普通の呼びかけで容易に開眼する／II-20 大きな声または体を揺さぶることにより開眼する／II-30 痛み刺激を加えつつ呼びかけを繰り返すとかろうじて開眼する
- III-100 痛み刺激に対し払いのけるような動作をする／III-200 痛み刺激で少し手足を動かしたり顔をしかめる／III-300 痛み刺激に反応しない

表の下に付加情報 **R（不穏）・I（糞便失禁）・A（自発性喪失）** を添える。

最後に Yes/No で降りる判定フローを置く。

```
目を開けているか？
├ はい   → I（1桁）
└ いいえ → 呼びかけ・刺激で開眼するか？
            ├ はい   → II（2桁）
            └ いいえ → III（3桁）
```

### 3. GCS：満点が「4・5・6」と並ぶことを軸にする

E（開眼）4 点・V（言語）5 点・M（運動）6 点、合計 3〜15 点。**満点が 4・5・6 と順に並ぶ**ことを枠として、各項目の中身を降ろす。

- E4 自発的に開眼／E3 呼びかけにより開眼／E2 痛み刺激により開眼／E1 開眼しない
- V5 見当識あり／V4 混乱した会話／V3 不適当な言葉／V2 理解不明の音声／V1 発語なし
- M6 命令に従う／M5 疼痛部位に手をもってくる／M4 逃避屈曲／M3 異常屈曲（除皮質硬直）／M2 伸展（除脳硬直）／M1 まったく動かない

あわせて 3 点を強調する。

1. **JCS は数字が大きいほど悪い。GCS は大きいほど良い。向きが真逆**
2. **合計の最小は 0 ではなく 3**。各項目に最低 1 点があるため
3. **最良反応で採る**。片麻痺があると麻痺側を見て M を低く見積もる誤りが起きる

### 4. 現場で効く注意点（カラウト）

- 記録は合計点だけでなく **内訳（E_V_M）** で残す。合計が同じでも中身が違えば意味が違う
- 挿管中の V は **1T** と記載する
- **前回と同じ刺激・同じ呼びかけ方で評価する**。既存の要復習問題と直結するため、ここで再度つなげる

### 5. モデルケースへの接続

ページ冒頭のモデルケース（60代男性・左被殻出血、**JCS 20／GCS E3V3M5**）を採点の実例として解説する。すでにページ内にいる患者なので、抽象的な表が具体例と結びつく。

- JCS 20 ＝ 大きな声または体を揺さぶることにより開眼する
- GCS E3（呼びかけで開眼）＋ V3（不適当な言葉）＋ M5（疼痛部位に手をもってくる）＝ **合計 11 点**

### 6. クイズ問題の追加（`topics/ich.json`）

暗記の定着を確認する手段として 3 問追加する。弱点モードで反復できるようになる。既存 19 問 → 22 問。

| # | 形式 | 問う内容 |
|---|---|---|
| 1 | mc | 大きな声で呼ぶと開眼するが、やめるとすぐ閉じる患者の JCS はどれか（II-20 の判定） |
| 2 | qa | GCS E3V3M5 を日本語で説明し、合計点を答える。あわせて JCS との向きの違いを述べる |
| 3 | mc | 右片麻痺があり、挿管中の患者の GCS の採点で正しいのはどれか（最良反応で採る・V は 1T） |

問題文・解説は既存問題の書式（`type`／`q`／`choices`／`answer`／`why`／`explain`）に合わせる。判定を問う形にし、数値の丸暗記を問う形にはしない。

追加後は `python3 build_index.py` を実行して `topics/index.json` の件数を更新する。`tags` に「GCS」を追加する（「JCS」は既存）。
