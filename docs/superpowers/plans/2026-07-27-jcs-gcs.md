````markdown
## 意識レベルの測り方（JCS/GCS）
観察セットの筆頭に置いた物差しの中身。**9個の数字を覚えるのではなく、桁を決める軸を1本入れる**と、あとは自動的に降りてくる。
### JCS（3-3-9度方式）＝「どれくらい強い刺激で覚醒するか」
桁を決めているのは**刺激の強さ**という軸1本だけ。

| 桁 | 覚醒の状態 | 数字 |
| --- | --- | --- |
| **I**（1桁） | 刺激しなくても覚醒している | 1・2・3 |
| **II**（2桁） | 刺激すると覚醒する（刺激をやめると眠る） | 10・20・30 |
| **III**（3桁） | 刺激しても覚醒しない | 100・200・300 |

そのうえで**各桁の中の1・2・3も「軽い → 重い」で共通**。つまり覚えるのは9個の数字ではなく、**「桁を決める軸」＋「各桁3段階」**の2階建てだけ。

| 桁 | JCS | 状態 |
| --- | --- | --- |
| I | 1 | だいたい意識清明だが、今ひとつはっきりしない |
| I | 2 | 見当識障害がある |
| I | 3 | 自分の名前・生年月日が言えない |
| II | 10 | 普通の呼びかけで容易に開眼する |
| II | 20 | 大きな声または体を揺さぶることにより開眼する |
| II | 30 | 痛み刺激を加えつつ呼びかけを繰り返すと、かろうじて開眼する |
| III | 100 | 痛み刺激に対し、払いのけるような動作をする |
| III | 200 | 痛み刺激で少し手足を動かしたり、顔をしかめる |
| III | 300 | 痛み刺激に反応しない |

付加情報として **R（不穏）・I（糞便失禁）・A（自発性喪失）** を数字の後ろに付ける（例：JCS 20-R）。
**判定は桁から降りる。**
- 目を開けているか？ → **はい：I（1桁）**
- いいえ。呼びかけ・揺さぶり・痛み刺激で開眼するか？ → **はい：II（2桁）**
- それでも開眼しない → **III（3桁）**
### GCS ＝ 満点が「4・5・6」と並ぶ
E（開眼）4点・V（言語）5点・M（運動）6点。**満点が4・5・6と順に並ぶ**のを枠にすると、各項目の段数を思い出せる。合計は3〜15点。

| 項目 | 点 | 反応 |
| --- | --- | --- |
| E（開眼） | 4 | 自発的に開眼 |
| E（開眼） | 3 | 呼びかけにより開眼 |
| E（開眼） | 2 | 痛み刺激により開眼 |
| E（開眼） | 1 | 開眼しない |
| V（言語） | 5 | 見当識あり |
| V（言語） | 4 | 混乱した会話 |
| V（言語） | 3 | 不適当な言葉 |
| V（言語） | 2 | 理解不明の音声 |
| V（言語） | 1 | 発語なし |
| M（運動） | 6 | 命令に従う |
| M（運動） | 5 | 疼痛部位に手をもってくる |
| M（運動） | 4 | 逃避屈曲 |
| M（運動） | 3 | 異常屈曲（除皮質硬直） |
| M（運動） | 2 | 伸展（除脳硬直） |
| M（運動） | 1 | まったく動かない |

<callout icon="⚠️" color="red_bg">
**いちばん混乱するところ**
- **JCSは数字が大きいほど悪い。GCSは数字が大きいほど良い。向きが真逆**
- GCSの合計の最小は0ではなく**3**。各項目に最低1点があるため
- **最良反応で採る**。片麻痺があるとき麻痺側で採ると、意識レベルではなく麻痺の重さを測ってしまう
</callout>
<callout icon="🧰" color="yellow_bg">
**記録・申し送りでの注意**
- 合計点だけでなく**内訳（E_V_M）**で残す。合計11点でも E4V1M6 と E3V3M5 では意味がまったく違う
- 挿管中のVは **1T**（T＝tube）と記載する
- **前回と同じ刺激・同じ呼びかけ方で評価する**。評価法が変わると「前回との差」が見えなくなり、悪化を見落とす
</callout>

**冒頭のモデルケースで採点してみる**（60代男性・左被殻出血、JCS 20／GCS E3V3M5）。
- **JCS 20**：刺激すると覚醒する（＝2桁）の真ん中。大きな声または体を揺さぶることにより開眼する
- **GCS E3**（呼びかけにより開眼）＋**V3**（不適当な言葉）＋**M5**（疼痛部位に手をもってくる）＝**合計11点**
````
