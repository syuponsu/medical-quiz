Notion「ピヴラッツ（クラゾセンタン）— SAH術後スパズム予防の管理」より取り込み（2026-07-30 時点）

🧭
作成時の前提：救命病棟／心電図・SpO₂・NIBP は常時装着／in-out は把握されている（A-line は条件付き）。病期＝動脈瘤処置後〜SAH発症15日目のスパズム期、到達点＝観察・アセスメント＋急変。

1. 概要・定義

  • クラゾセンタンナトリウム。選択的ETA受容体拮抗薬。効能・効果は「脳動脈瘤によるくも膜下出血術後の脳血管攣縮、及びこれに伴う脳梗塞及び脳虚血症状の発症抑制」
  • 2022年3月承認。収載時薬価 80,596円/V（通常1日2V使用）
  • SAH後の遅発性脳血管攣縮は約1/3の患者に生じ、脳血流低下から脳梗塞・脳虚血症状を起こす。本剤は攣縮そのものを抑えにいく薬
⚠️
要確認：脳卒中治療ガイドラインでの「推奨度B・エビデンスレベル中」は下地のSNS資料由来で原本未確認。加えて現行版は〔改訂2025〕であり、下地の「改訂2023が最新」は古い。推奨の文言は原本で確認する。

投与対象の絞り込み（＝うちの患者に使えるか）

禁忌

  • 本剤の成分に対し過敏症の既往歴のある患者
  • 妊婦または妊娠している可能性のある患者
  • 重度肝機能障害（Child-Pugh分類クラスC）
  • 頭蓋内出血が継続している患者

開始条件

  • 動脈瘤の処置が完了した患者であること
  • 投与期間は術後早期に開始し、くも膜下出血発症15日目まで
  • 要確認：「SAH発症48時間以内を目安に開始」「WFNS分類V・広範囲脳梗塞合併・Fisher分類3以外では有効性/安全性未確立」は下地資料および検索要約で一致するが、添付文書原文を直接確認できていない

2. 病態 → 観察の理由づけ

血腫の赤血球が溶血 → オキシヘモグロビン → ET-1↑ → 血管平滑筋のETA受容体に結合 → 持続的な血管収縮＝遅発性脳血管攣縮 → 脳血流低下 → 遅発性脳虚血・脳梗塞

  • 本剤はETAを選択的に遮断して攣縮を抑える（ETB受容体を残す設計）が、臨床上は体液貯留が最大の副作用として残る
  • 重大な副作用としての体液貯留：胸水 13.3%・肺水腫 11.0%・脳浮腫 0.5%、頭蓋内出血 0.5%、硬膜外血腫（頻度不明）
🎯
この教材の核：従来のスパズム管理は「脱水を避け、ややプラスバランス」。本剤は体液貯留を起こすため、従来の水分管理とベクトルが逆になる。呼吸（胸水・肺水腫）と神経所見（攣縮・脳浮腫）を同時に天秤にかける観察が必要になる。
  • 自分の理解：血圧低下・貧血（ともに1〜3%未満）の是正手段（輸液増量・輸血）は循環血液量を増やす方向。つまり副作用対策が別の副作用を煽る構造になっている
  • 投与終了後も遅発性脳血管攣縮は起こりうるため、15日目で神経観察を終わりにしない

エリル（ファスジル）との作用点の違い

項目ピヴラッツ（クラゾセンタン）エリル（ファスジル）
作用点ETA受容体拮抗（攣縮の引き金を遮断）Rhoキナーゼ阻害（平滑筋の収縮を抑制）
投与単独ルートで17mL/時の持続、24時間ごと交換1日2〜3回、30分かけて点滴
主な副作用体液貯留、出血、血圧低下、貧血、低Na、肝機能異常、鼻閉出血、血圧低下、腎機能障害など

併用は可能だが併用注意。ファスジル・血管拡張薬は血圧低下を増強、オザグレルは出血傾向を増強、リファンピシン/OATP1B1・1B3阻害薬は本剤の血中濃度を上げる、QT延長薬は心室性不整脈のリスクを上げる。

3. 投与管理（インシデント直結）

項目規定
組成クラゾセンタン300mg（150mg×2V＝12mL）＋生理食塩液500mL
速度17mL/時（＝10mg/時）・容量型の持続注入ポンプを使用
期間術後早期に開始し、SAH発症15日目まで
交換24時間ごとに交換し、残液は廃棄
ルート中心ラインの専用ルーメン、または専用の注入ラインを用いて単独投与
フィルター0.2μmフィルターを通して投与
減量規定中等度肝機能障害（Child-Pugh B）＝半量の5mg/時／リファンピシン併用＝1/4の2.5mg/時

上記はいずれも添付文書の規定。

🚨
沈殿・結晶化：pHが7より低い場合や、他の輸液剤と直接接触した場合に沈殿する可能性がある。だから「単独投与」と「0.2μmフィルター」の二重構えになっている。
・単独投与＝一次予防（結晶をそもそも作らせない）／フィルター＝二次防御（できた結晶を患者に入れない）
・現場で実際にあったトラブル（下地）＝急変時に側管を使って結晶化した／フィルターの使用を忘れた／他部署での処置中に急速投与された
・急変時に手近なルートとして使われないよう、ピヴラッツのラインは見て分かるように区別し、別ルートを確保しておく
  • 自分の理解：フィルターの実装は「0.2μmフィルター内蔵の輸液セットを使う」か「通常ラインに単体のインラインフィルターを後付けする」かのどちらか。自部署がどの方式かを把握しておく（付け忘れは後付け方式で起きやすい）。一般的な輸液セットの点滴筒のろ過網は目が粗く（15μm程度）、0.2μmの微小結晶は通過する
  • 自分の理解：CV用のフィルター付き輸液セットを流用する場合は、①孔径が0.2μmか（脂肪乳剤を通す1.2μm製品では要件を満たさない）②そのラインを他剤と共有しない専用にできるかの2点を確認する
  • 要確認：1V＋生食250mL、残液を廃棄せず使い切る等の運用が現場に存在するが添付文書外。そうした指示のときは根拠を確認する
  • 流量が17mL/時でない指示が出たら、減量規定（肝機能・併用薬）に該当するのかを確認できる

4. 受け持ち時の観察セット

ラウンドの順（意識・呼吸・循環・体液・栄養・症状・ライン）に、本剤で特に見る点を差し込む。

  • 意識・神経：JCS/GCS、瞳孔、麻痺、失語、視野障害、半側空間無視 → 新規の所見を拾う。脳浮腫・頭蓋内出血・遅発性脳虚血のいずれもここに出る。脳室ドレーン排液・頭蓋内圧センサー値の変化も併せて見る
  • 呼吸：呼吸数トレンド、SpO₂の追従、乾性咳嗽、息切れ、聴診、酸素需要の増加 → 胸水・肺水腫
  • 循環：血圧（下がる方向に注意）、脈圧、心電図モニタでのQT間隔
  • 体液：毎日同条件での体重、顔面・全身の浮腫（開眼できるか）、尿量、中心静脈圧
  • 栄養：食思・摂取量（食思不振→貧血・アルブミン低下→攣縮に不利、離床も進まない）
  • 症状：頭痛（強さと鎮痛薬の効き）、鼻閉（3%以上の副作用。ほぼ経過観察でよいが、頭痛と重なると離床が進まない）
  • ライン：単独か／フィルターの有無／ポンプ流量／残量と交換時刻

タイミング：勤務開始時（前勤務との差分をとる）／検温時／食後（摂取量）／夜間（呼吸数・酸素化・意識レベル）

📅
胸水・肺水腫の発現ピークは投与開始5〜6日目（コイリング術で平均6.1日、クリッピング術で5.2日）。攣縮のピークより早く来る。この時期は呼吸と体重を特に厚く見る。

5. データの読み方（3本柱）

① モニタ（波形・トレンド）

  • QT間隔：投与開始前および投与中に心電図を測定することが望ましいとされる。投与前の12誘導を把握しておき、比較する。要確認：下地資料の「QTc 0.468秒以上で延長、0.5秒以上で致死性不整脈ハイリスク」は原本未確認
  • 呼吸数：体液貯留で最も早く動く。自分の理解：SpO₂は遅れて追従するので、SpO₂が保たれていても呼吸数と酸素需要が上がっていれば動いていると読む
  • 血圧：血圧低下が起こりうる。血圧が適切にコントロールされている状況下で投与を開始する

② in-outバランス（本剤の主戦場）

  • 本剤だけで約408mL/日（17mL/時×24時間）が入る。他の輸液・薬剤・経口を足した総量で考える
  • 施設プロトコルの例：食事摂取可の患者は500〜1,000mL/日、摂取不可の患者は1,000〜1,500mL/日の水分制限（施設差あり）
  • 読む順：体重の日差 → 累積バランス → 時間尿量。自分の理解：尿量の減少は体液貯留の前触れとして扱う
  • 自分の理解：脳浮腫に対してグリセオール等を使う場面では、投与量そのものが体液貯留を煽る側に働く。従来の「攣縮予防のためのプラス寄り管理」と衝突することを意識する
  • 指標の仕分け：コア指標＝体重・呼吸数・酸素需要／補助指標＝中心静脈圧・尿量／単独では判断しない＝SpO₂の単発値

③ 採血・ABG

  • Hb：ヘモグロビン低下があらわれることがあるため投与前後で測定。貧血は酸素運搬能を下げ虚血に不利
  • Na：低ナトリウム血症（1〜3%未満）。自分の理解：SAHではSIADHやCSWも重なるため、水分制限とNa補正の方向が競合しうる
  • 肝機能（AST・ALT・T-Bil）：定期的に測定する
  • ABG：呼吸状態の評価に有効。P/F比の悪化を追う
  • 突き合わせの読み：自分の理解：QT間隔はK・Mg・Caでも動くので心電図だけで薬剤性と決めない。体重増＋呼吸数増＋P/F低下が揃えば体液貯留と読む
🛑
肝機能による投与中止基準（いずれかに該当したら中止）
・肝酵素（AST、ALT）が臨床的に顕著に上昇した場合
・総ビリルビン値が基準値上限の2倍を超えた場合
・黄疸などの肝障害の徴候が認められた場合
また、頭蓋内出血が認められた場合は直ちに投与を中止する。

6. 看護介入と効果判定

介入効いたかを何で確かめるか
血圧低下 → 指示による輸液調整・昇圧薬MAPの回復と同時に、呼吸数・酸素需要・体重が悪化していないか
貧血 → 輸血の検討Hbの上昇と、呼吸状態が過負荷方向に振れないか
体液貯留 → 水分制限・利尿薬・酸素・体位（頭部挙上は頭蓋内圧の指示範囲で）体重の減少、尿量、呼吸数、酸素需要、聴診所見
頭痛 → 指示鎮痛薬（肝機能に配慮した薬剤選択）疼痛スケール、離床・リハビリが進むか
食思不振 → 少量高栄養をこまめに（水分制限と整合させる）摂取量、Alb・Hb、リハビリの進捗
新規の神経症状 → まずCTCT結果と症状の推移。降圧は出血所見を確認してから
  • 要確認：「頭痛に対して肝代謝のアセリオ・カロナールは避けるべき」は下地資料に載る医師の意見で、添付文書に該当記載はない。施設・主治医の方針を確認する
  • 要確認：「新規症状の原因が虚血なら降圧で増悪させる。虚血か出血かは見た目で判断できないのでCTを先に」は下地資料由来（考え方としては妥当だが原本未確認）

7. 実務メモ・落とし穴

🧠
自分の理解（下地：SNSの現場の声を含む。診療ガイドラインそのものではない）
・投与中止に至る症例で多いのは肺水腫・心不全による呼吸状態の悪化（再挿管）。「呼吸を守れているか」が投与継続の生命線
・全身の浮腫が強くなると末梢確保が難しくなる → 早めのライン計画を立てる
・投与終了＝観察終了ではない（遅発性攣縮は終了後も起こりうる）
・高額薬（収載時 80,596円/V・1日2V）。残液廃棄やルート事故のコストが大きい
・良い面として「交換が1日1回で管理しやすい」「緊急の血管撮影やエリルの動注症例が減った」という声もある
