概要・定義

脳実質内の血管が破綻して血腫を作る病態。最多の原因は高血圧で、慢性高血圧により脆弱化・動脈硬化を起こした細い穿通枝が破れる（MSD）。ほかに脳アミロイド血管症（高齢者の脳葉型出血）、動静脈奇形、動脈瘤、外傷、脳腫瘍、過剰な抗凝固療法。

急性期に怖い理由は3つ。①血腫そのものによる破壊と圧迫 ②発症後数時間の血腫増大 ③脳浮腫による頭蓋内圧亢進 → 脳ヘルニア。急性期看護は主に②と③を捕まえることに向けられる。

部位頻度主な症状眼球・瞳孔所見
被殻40%対側の片麻痺・感覚障害、失語（優位半球）患側（病巣側）への共同偏視
視床30%感覚障害が優位、対側片麻痺、脳室穿破 → 水頭症内下方偏位（鼻先を見る）

頻度・眼球所見＝健康長寿ネット、共同偏視＝ナース専科 看護用語集

病態 → 観察の理由づけ

病態のステップ体で起きることだから何を見るか
穿通枝の破綻・血腫形成局所の脳組織が破壊・圧迫される麻痺・感覚障害・失語などの巣症状
血腫が内包を圧迫／内包に及ぶ運動・感覚神経の通り道が遮断される出血と反対側の片麻痺・感覚障害
血腫増大（発症〜6〜24時間に最多。抗凝固例ではより遅くまで）症状が階段状に悪化頻回の意識レベル確認、再検CT。血腫1mLの増大ごとに死亡リスク5%増（EMCrit）

脳細胞の障害痙攣発作（約10%に出現／EMCrit）発作の有無。痙攣は酸素消費を増やし脳に不利

受け持ち時の観察セット

ラウンドで見る順に、脳出血で特に見る点を差し込む。この疾患の観察は「今の値」より「前回との差」が主役。

順見るものこの疾患での要点
意識JCS・GCS最重要。同じ刺激・同じ呼びかけ方で評価して差を見る。1桁 → 2桁の変化は再出血・浮腫増悪・水頭症を疑う分岐点
瞳孔左右差・対光反射瞳孔不同の出現＝テント切痕ヘルニアを疑う。意識低下より先に出ることがある
麻痺MMT・上肢バレー前勤務からの悪化がないか。「前と同じ」を確認することに意味がある
呼吸数・パターン・SpO₂チェーンストークス・失調性呼吸は脳幹障害。人工呼吸器管理なら設定とPaCO₂を必ずセットで見る
循環BP・HR・脈圧降圧目標内か。血圧上昇＋徐脈は「落ち着いた」ではなくクッシング現象を疑う
ライン・ドレーン降圧薬持続・抗浮腫薬・脳室ドレーン降圧薬の一時中断は血圧再上昇＝血腫増大に直結。脳室ドレーンは高さ・排液量・性状
その他頭痛・嘔吐・痙攣・体温嘔吐は頭蓋内圧亢進のサイン。発熱は脳の酸素需要を上げる

観察のタイミング：発症〜6時間は血腫増大の最多時間帯なので頻回。安定例でも約6時間後と24時間後に再検CT、神経学的変化があればその都度（EMCrit）。

意識レベルの測り方（JCS/GCS）

観察セットの筆頭に置いた物差しの中身。9個の数字を覚えるのではなく、桁を決める軸を1本入れると、あとは自動的に降りてくる。

JCS（3-3-9度方式）＝「どれくらい強い刺激で覚醒するか」

桁を決めているのは刺激の強さという軸1本だけ。

桁覚醒の状態数字
I（1桁）刺激しなくても覚醒している1・2・3
II（2桁）刺激すると覚醒する（刺激をやめると眠る）10・20・30
III（3桁）刺激しても覚醒しない100・200・300

そのうえで各桁の中の1・2・3も「軽い → 重い」で共通。つまり覚えるのは9個の数字ではなく、「桁を決める軸」＋「各桁3段階」の2階建てだけ。

桁JCS状態
I1だいたい意識清明だが、今ひとつはっきりしない
I2見当識障害がある
I3自分の名前・生年月日が言えない
II10普通の呼びかけで容易に開眼する
II20大きな声または体を揺さぶることにより開眼する
II30痛み刺激を加えつつ呼びかけを繰り返すと、かろうじて開眼する
III100痛み刺激に対し、払いのけるような動作をする
III200痛み刺激で少し手足を動かしたり、顔をしかめる
III300痛み刺激に反応しない

付加情報として R（不穏）・I（糞便失禁）・A（自発性喪失） を数字の後ろに付ける（例：JCS 20-R）。

判定は桁から降りる。

  • 目を開けているか？ → はい：I（1桁）
  • いいえ。呼びかけ・揺さぶり・痛み刺激で開眼するか？ → はい：II（2桁）
  • それでも開眼しない → III（3桁）

GCS ＝ 満点が「4・5・6」と並ぶ

E（開眼）4点・V（言語）5点・M（運動）6点。満点が4・5・6と順に並ぶのを枠にすると、各項目の段数を思い出せる。合計は3〜15点。

項目点反応
E（開眼）4自発的に開眼
E（開眼）3呼びかけにより開眼
E（開眼）2痛み刺激により開眼
E（開眼）1開眼しない
V（言語）5見当識あり
V（言語）4混乱した会話
V（言語）3不適当な言葉
V（言語）2理解不明の音声
V（言語）1発語なし
M（運動）6命令に従う
M（運動）5疼痛部位に手をもってくる
M（運動）4逃避屈曲
M（運動）3異常屈曲（除皮質硬直）
M（運動）2異常伸展（除脳硬直）
M（運動）1まったく動かない
⚠️
いちばん混乱するところ
  • JCSは数字が大きいほど悪い。GCSは数字が大きいほど良い。向きが真逆
  • GCSの合計の最小は0ではなく3。各項目に最低1点があるため
  • 最良反応で採る。片麻痺があるとき麻痺側で採ると、意識レベルではなく麻痺の重さを測ってしまう
🧰
記録・申し送りでの注意
  • 合計点だけでなく内訳（E_V_M）で残す。合計11点でも E4V1M6 と E3V3M5 では意味がまったく違う
  • 挿管中のVは 1T（T＝tube）と記載する
  • 前回と同じ刺激・同じ呼びかけ方で評価する。評価法が変わると「前回との差」が見えなくなり、悪化を見落とす

冒頭のモデルケースで採点してみる（60代男性・左被殻出血、JCS 20／GCS E3V3M5）。

  • JCS 20：刺激すると覚醒する（＝2桁）の真ん中。大きな声または体を揺さぶることにより開眼する
  • GCS E3（呼びかけにより開眼）＋V3（不適当な言葉）＋M5（疼痛部位に手をもってくる）＝合計11点

データの読み方（3本柱）

① モニタ

  • 血圧が主役。急性期はできるだけ早期に収縮期血圧140mmHg未満へ降圧することが妥当（推奨度B・エビデンスレベル高）、下限は110mmHg超を維持することを検討してよい（推奨度C・レベル低）／脳卒中治療ガイドライン2021〔改訂2025〕
  • AHA・ASA 2022：来院時の収縮期血圧が150〜220mmHgなら140mmHgを目標に130〜150で維持。130未満まで下げるのは有害の可能性（EMCrit）
  • 見るのは単発値ではなくトレンド。持続降圧下で「じわじわ上がる」＝再出血・頭蓋内圧亢進／「急に下がる」＝降圧しすぎ、または抗浮腫薬による利尿の影響
  • クッシング現象は脳ヘルニアの警告（MSD 脳ヘルニア）。血圧が高いのを「降圧すればいい」と処理しない
  • 反応の速さ：血圧＝分単位で速い／HR・呼吸パターンの変化＝速いが見落としやすい

② in-outバランス

軸内容
IN降圧薬・抗浮腫薬のキャリア量。過剰な自由水（低張液）は脳浮腫を悪化させるため避ける
OUTグリセオール／マンニトール投与後の尿量増加は薬理作用そのもの。問題はその後に何が起きるか
  • 抗浮腫薬 → 血管内へ水を引き込む → 尿量増加 → 循環血液量減少 → 血圧低下の連鎖に注意。脳灌流圧が落ちれば二次性脳損傷になる
  • 読み方のコツ：「脳のむくみは引きたい／でも脱水で脳灌流は落としたくない」のせめぎ合い。累積バランスをどこまでマイナスに振るかは血圧・尿量・Naとセットで判断する
  • 反応の速さ：時間尿量＝時間単位（速い）／累積バランス・体重＝日単位（遅い）

③ ABG・電解質

  • コア指標：PaCO₂、Na、血漿浸透圧、血糖、体温
  • 補助指標：pH、HCO₃⁻、K、Hb、凝固（PT-INR・血小板）
  • 単独では判断しない：PaCO₂の絶対値、単回の血圧値

PaCO₂ ＝ この疾患のいちばんの落とし穴

  • PaCO₂は脳血管径を直接動かす。低下 → 脳血管収縮 → 脳血流減少 → 頭蓋内圧低下／上昇 → 脳血管拡張 → 頭蓋内圧上昇
  • 頭蓋内圧が20mmHgを超える場合に治療開始。段階的にマンニトール・グリセオール、過換気（PaCO₂ 30〜35mmHg）（りんくう総合医療センター）。脳ヘルニア切迫時は26〜30mmHgまで下げることがある（MSD 脳ヘルニア）
  • 正常値35〜45mmHgと比べて「低い＝異常」と報告しない。意図的に下げているのか、過換気の結果なのかを必ず確認する
  • 過換気はあくまで時間稼ぎ。下げすぎれば脳虚血を招く

Na・浸透圧

  • 血清浸透圧は295〜320mOsm/kgを維持。頭蓋内圧の目標は20mmHg以下、脳灌流圧50〜70mmHg（MSD 脳ヘルニア）
  • 低Naは脳浮腫を悪化させる。脳出血後はSIADH／中枢性塩類喪失（CSW）の鑑別が問題になる
  • グリセオールの副作用：低カリウム血症・高ナトリウム血症・非ケトン性高浸透圧性高血糖・脱水傾向、重大な副作用に乳酸アシドーシス（添付文書）

モニタ所見と採血データの突き合わせ

組み合わせ何がわかるか
血圧上昇＋徐脈＋呼吸不整 ＋ 意識レベル低下クッシング現象＝頭蓋内圧亢進・脳ヘルニア切迫。「降圧すればいい」ではない
PaCO₂低値 ＋ 人工呼吸器設定意図的な過換気か、不要な過換気か。後者なら医師へ報告し設定調整
尿量増加 ＋ 血圧低下 ＋ Na・浸透圧上昇抗浮腫薬の効きすぎ（循環血液量減少）
Na低下 ＋ 意識レベル低下低Naによる脳浮腫増悪。SIADH／CSWの鑑別へ
発熱 ＋ 血圧上昇 ＋ 意識低下脳の酸素需要増大。解熱と原因検索

指標ごとの反応の速さ：血圧＝分／PaCO₂＝分〜十数分（換気設定に即応）／尿量＝時間／Na・浸透圧＝時間〜日（遅れて追従）／意識レベル＝連続的だが評価は間欠。

看護介入と効果判定

介入効いたかを何で確かめるか
降圧（ニカルジピン等のCa拮抗薬を微量点滴静注）収縮期血圧140mmHg未満を維持できているか。ただし110mmHg以下へ落とさない。麻痺・意識の悪化は下げすぎのサイン
抗浮腫薬（グリセオール200〜500mLを1回2〜3時間かけて1日1〜2回／マンニトール）意識レベル・瞳孔の改善。尿量増加に伴う血圧低下、K低下、Na上昇、血糖上昇をセットで確認
頭部挙上 15〜30°（30°を超えない）・頭部正中位30°挙上で頭蓋内圧が下がる一方、脳灌流圧・脳血流は落ちない（Feldman 1992、Ramos 2024）。30°を超えても頭蓋内圧はそれ以上下がらないので上限とする（→ Q&Aコーナー）。頸部の屈曲・過度な回旋、きついネックカラーや気管切開バンドも静脈還流を妨げるので同時に確認。人工呼吸器装着中はVAP予防の面でも挙上が有利。最終的には施設・主治医の指示が優先
呼吸管理（挿管・人工呼吸器）PaCO₂が指示された目標域にあるか。ETCO₂は傾向把握に使い、値の判断はABGで
痙攣への対応予防的な抗痙攣薬のルーチン投与は推奨されない（EMCrit／AHA・ASA 2022）。指示があれば確実に投与できているか、なければ発作出現に備える。発作時は気道・酸素化を最優先
発熱への対応解熱と原因検索。体温低下と意識レベル・血圧の関係を見る
再検CTへの申し送り「前回と比べてどこが変わったか」を数値と所見で渡せているか

実務メモ・落とし穴

🧰
裏取り区分：一部「自分の理解」（現場での読み筋）を含む
  • PaCO₂低値を機械的に「異常」と報告しない。脳出血では意図的に低めに管理していることがある。指示・設定・目的をセットで確認してから報告する
  • 血圧高値＋徐脈を「落ち着いている」と読まない。クッシング現象は脳ヘルニア切迫のサイン
  • 瞳孔不同は意識レベル低下より先に出ることがある。意識だけを追わない
  • 鎮静下では麻痺の悪化も意識の変化も隠れる。瞳孔・血圧・呼吸パターンなど鎮静に隠れない所見の比重を上げる
  • 降圧しすぎは二次性脳損傷。脳灌流圧＝平均動脈圧 − 頭蓋内圧なので、頭蓋内圧が高い状態では同じ血圧でも脳への灌流は下がっている
  • 抗浮腫薬の「効いた」と「効きすぎた」は同じ尿量増加として現れる。血圧・Na・Kを必ず一緒に見る
  • 抗血小板薬内服中の脳出血に血小板輸血は勧められない（推奨度D・エビデンスレベル高）。ワルファリン内服中はプロトロンビン複合体製剤による中和（ガイドライン2021〔改訂2025〕）
  • 手術適応外＝何もしない、ではない。発症から時間が経ち昏睡が続く例では手術をしても回復が見込めず適応外となることがある。家族の思いを聴きながら過ごし方を調整することが看護の中心になる
❓

  • JCS 2桁以上で外科的治療の適応：看護向け情報源の記載で、ガイドライン原文では未確認
  • 橋出血の pinpoint pupil：教科書的に知られるが、今回当てた出典では「正中位固定」までの記載

  • 挿管中のGCSでVを「1T」と記載する運用：広く使われているが、学会等の一次情報では確認できなかった。「NT」と記載する流儀も併存しており、記載法は施設ルールに依存する可能性がある
  • JCSの付加情報 R（不穏）・I（糞便失禁）・A（自発性喪失）：広く知られているが、太田らの原著本文で直接確認できていない
  • JCS・GCS各段階の日本語文言：出典によって表現が揺れる（例：JCS I-1 を「見当識は保たれているが意識清明ではない」と表現する資料もある）。本ページは一般に流布している表現を採用している

Q&Aコーナー

受け持ち後の気づきをここに追記して育てる。

Q. うちの病院は「ギャッチ30度以上あげるな」の指示が多い。急性期はあまり上げない方がいいのでは？

A. 「30°まで上げる」と「30°を超えない」は同じことを言っている。30°は目標であり、同時に上限。

  • 30°まで上げる理由：頭部挙上は静脈還流を促して頭蓋内圧を下げる。急性期脳損傷のメタ解析（Ramos 2024）では、30°は仰臥位より ICP が平均 5.58mmHg 低い（95% CI 4.41〜6.74、p<0.00001）
  • それでも脳灌流は落ちない：Feldman 1992（22例、0° vs 30°）では30°で平均頸動脈圧は下がるが（89.5⇒84.3mmHg）、ICPがそれ以上に下がる（19.7⇒14.1mmHg）ため、CPP・CBFは有意に変化しなかった。メタ解析でもCPPは30°と仰臥位で差なし（MD −2.48mmHg、p＝0.13）
  • だが30°を超えては上げない理由：同じメタ解析で、「45° vs 30°」だけが、さらに挙上してもICPが有意に下がらなかった唯一の比較。つまり30°を超えると得るものがなく、動脈圧の低下だけが残る
  • フラットが良いという議論の出どころ：Wojner-Alexander 2005は、30°→0°で中大脳動脈の平均血流速度が平均20%上昇したと報告した（30→15°で12%、15→0°でさらに8%、p≦0.025）。ただしこれはMCAが閉塞した急性期脳梗塞20例のデータで、脳出血のデータではない。閉塞の先へ側副血行を稼ぎたい脳梗塞と、ICPを下げたい脳出血では前提が違う
  • 転帰では差が出ていない：HeadPoST（NEJM 2017、11,093例）では 0° と 30°以上を24時間維持して、90日後mRSに差なし（OR 1.01、95% CI 0.92〜1.10、p＝0.84）、死亡率7.3% vs 7.4%、肺炎を含む重篤な有害事象にも差なし。ただし85%が脳梗塞・脳出血は15%
  • 結論：0°でも45°でもなく15〜30°に収める、という指示。「30度以上あげるな」は上限の指示として合理的。ただし「上げると脳灌流圧が下がるから危険」という理由づけはデータと合わない。30°まではCPPを犠牲にせずICPを下げられるが、それ以上は上乗せの利益がないと読む
